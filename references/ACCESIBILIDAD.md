# Base de accesibilidad

## Principio

La accesibilidad se debe incorporar desde la planificación y no como una revisión final. Las comprobaciones automáticas ayudan, pero no sustituyen la revisión manual ni las pruebas con tecnologías de apoyo.

## Requisitos comunes

- Contraste suficiente para texto, controles y elementos gráficos esenciales.
- Jerarquía y estructura semántica correctas.
- Información no dependiente solo del color, posición, sonido o forma.
- Texto alternativo para imágenes informativas.
- Lenguaje claro y enlaces descriptivos.
- Orden de lectura lógico.
- Tablas con encabezados identificables.
- Vídeos con subtítulos y contenido sonoro relevante con alternativa textual.

## Documentos

- Usar estilos de encabezado y listas reales.
- Definir idioma y título del documento.
- Exportar PDF etiquetado.
- Revisar orden de lectura, marcadores, enlaces y texto alternativo.
- Evitar documentos escaneados sin capa de texto.

## Presentaciones

- Usar títulos únicos y orden de lectura correcto.
- Mantener tamaños legibles y contraste en el dispositivo real.
- Describir verbalmente gráficos e imágenes relevantes.
- Subtitular vídeos.

## Web

- Operación completa mediante teclado.
- Foco visible.
- Reflujo y zoom sin pérdida de contenido.
- Etiquetas, instrucciones y errores comprensibles en formularios.
- HTML semántico y nombres accesibles.

## Verificación mínima

1. Revisión automática con una herramienta adecuada al formato.
2. Revisión manual de estructura, contraste y alternativas.
3. Prueba de teclado en productos web.
4. Revisión con lector de pantalla en los flujos principales cuando proceda.
5. Corrección y repetición de las pruebas.
