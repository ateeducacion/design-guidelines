# Crear un informe

## Cuándo usar esta skill

Cuando se solicite crear, transformar, maquetar o revisar un informe, memoria, propuesta, acta o documento institucional.

## Contexto obligatorio

Leer, en este orden:

1. `../../DESIGN.md`
2. `../../design/informes/DESIGN.md`
3. `../../references/ACCESIBILIDAD.md`
4. `../../references/FUENTES.md`
5. La plantilla concreta, si existe.

## Flujo

1. Identificar audiencia, finalidad, formato final y estado del documento.
2. Proponer una estructura antes de maquetar cuando el contenido no la tenga.
3. Aplicar estilos semánticos y una jerarquía limitada.
4. Usar únicamente recursos institucionales oficiales.
5. Crear tablas y gráficos con fuente, unidad y periodo.
6. Preparar el archivo editable y exportar el PDF etiquetado.
7. Ejecutar la lista de comprobación de la guía de informes.
8. Informar de cualquier requisito que no haya podido verificarse.

## Restricciones

- No inventar logotipos, colores, cargos, datos ni fuentes.
- No usar tablas o cuadros de texto para maquetar el documento completo.
- No sacrificar legibilidad para reducir páginas.
- No afirmar que un PDF es accesible sin haber realizado comprobaciones.

## Entregables

- Archivo editable cuando proceda.
- PDF final.
- Resumen de fuentes y excepciones.
- Resultado de la revisión de accesibilidad.
