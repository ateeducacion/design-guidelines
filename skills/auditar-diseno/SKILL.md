# Auditar diseño

## Contexto obligatorio

Leer `../../DESIGN.md`, la guía específica del formato y `../../references/ACCESIBILIDAD.md`.

## Proceso

1. Identificar el formato, audiencia, finalidad y versión auditada.
2. Separar requisitos obligatorios, recomendaciones y preferencias.
3. Revisar identidad institucional, estructura, legibilidad, accesibilidad, datos y consistencia.
4. Registrar cada hallazgo con ubicación, gravedad, evidencia y corrección propuesta.
5. Distinguir lo verificado de lo que requiere una prueba adicional.
6. Priorizar problemas que impidan comprender, usar o publicar el material.

## Niveles

- **Bloqueante:** incumplimiento legal, identidad incorrecta, pérdida de información o imposibilidad de uso.
- **Alta:** barrera relevante de accesibilidad o comprensión.
- **Media:** inconsistencia que afecta a calidad o mantenimiento.
- **Baja:** mejora recomendable sin impacto funcional inmediato.

## Formato del resultado

Para cada hallazgo indicar:

- nivel;
- ubicación;
- regla incumplida;
- evidencia;
- propuesta concreta;
- estado de verificación.

No declarar conformidad completa cuando no se hayan ejecutado todas las pruebas necesarias.
