# Plantillas

Este directorio contendrá plantillas aprobadas para documentos, informes, presentaciones y páginas web.

## Estructura prevista

```text
templates/
├── informes/
├── presentaciones/
└── web/
```

## Requisitos de una plantilla

- Indicar nombre, finalidad, versión, responsable y fecha de revisión.
- Enlazar el `DESIGN.md` que aplica.
- Usar recursos institucionales oficiales.
- Incluir estilos y componentes reutilizables.
- Superar la lista de comprobación de accesibilidad del formato.
- Incluir un ejemplo completo y unas instrucciones breves de uso.
- Evitar contenido personal o datos reales en los ejemplos.

## Estados

- `draft`: en preparación; no usar para publicaciones definitivas.
- `review`: pendiente de validación funcional, visual o institucional.
- `approved`: validada para el uso indicado.
- `deprecated`: sustituida; se conserva temporalmente para migraciones.

Una plantilla no debe marcarse como `approved` solo porque se vea correctamente. Debe revisarse también su estructura, accesibilidad, exportación y mantenimiento.
