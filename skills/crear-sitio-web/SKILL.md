# Crear un sitio o una página web

## Contexto obligatorio

Leer:

1. `../../DESIGN.md`
2. `../../design/web/DESIGN.md`
3. `../../references/ACCESIBILIDAD.md`
4. `../../references/FUENTES.md`

## Flujo

1. Identificar audiencia, tareas, contenidos, responsables y ciclo de mantenimiento.
2. Definir arquitectura, navegación y jerarquía de contenidos.
3. Crear primero HTML semántico y funcional.
4. Aplicar estilos y componentes reutilizables.
5. Incorporar interacción progresivamente y sin romper el uso con teclado.
6. Revisar rendimiento, privacidad, seguridad y dependencias.
7. Probar en móvil, escritorio, zoom, teclado y lector de pantalla en los flujos principales.
8. Documentar excepciones y deuda pendiente.

## Restricciones

- No usar imágenes para representar texto que pueda ser HTML.
- No crear controles personalizados cuando exista un elemento nativo adecuado.
- No añadir rastreadores ni dependencias de terceros sin justificación.
- No considerar suficiente una auditoría automática.
- No inventar identidad visual ni contenido institucional.

## Entregables

- Código fuente mantenible.
- Documentación de componentes y decisiones.
- Resultado de pruebas de accesibilidad y rendimiento.
- Inventario de dependencias y servicios externos.
