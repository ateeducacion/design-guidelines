# Logotipos y marcas oficiales

Este directorio reúne el inventario de marcas que pueden utilizarse en las plantillas. Los archivos binarios deben conservarse sin modificaciones y acompañarse de metadatos de procedencia.

## Gobierno de Canarias

**Estado:** fuente oficial verificada.

La zona oficial de identidad gráfica ofrece variantes en PDF, PNG, JPG y, para determinados usos, EPS. Debe elegirse el modelo según el soporte, el fondo y las reglas del manual.

- Portal: https://www.gobiernodecanarias.org/identidadgrafica/
- Descargas: https://www.gobiernodecanarias.org/identidadgrafica/descargas/
- Modelo 1 color, PNG: https://www.gobiernodecanarias.org/cmsgob2/export/sites/identidadgrafica/marcas/marcas_publicidad/marca_gobcan_con_claim/Logo_GobCan_claim_color_mod1.png
- Modelo 2 color, PNG: https://www.gobiernodecanarias.org/cmsgob2/export/sites/identidadgrafica/marcas/marcas_publicidad/marca_gobcan_con_claim/Logo_GobCan_claim_color_mod2.png

### Reglas

- No reconstruir la marca a partir de tipografías o imágenes separadas.
- No cambiar colores, proporciones, orientación ni disposición.
- No recortar el área de respeto.
- Usar las versiones blanca, negra o especial únicamente en los casos contemplados por el manual.
- No asumir que el modelo 1 sirve para todos los soportes.

## Área de Tecnología Educativa

**Estado:** símbolo publicado en un sitio oficial de ATE; pendiente de localizar o aprobar un archivo maestro y un manual específico.

- Página oficial de ATE: https://www3.gobiernodecanarias.org/medusa/ecoescuela/ate/
- Imagen publicada: https://www3.gobiernodecanarias.org/medusa/ecoescuela/ate/files/2021/04/ate-272x281.png
- Página descriptiva oficial: https://www.gobiernodecanarias.org/educacion/web/servicios/tecnologia_educativa_medusa/index.html

### Reglas provisionales

- No vectorizar, redibujar ni recolorear el símbolo.
- No añadir por cuenta propia el nombre completo o una firma institucional.
- No tratar esta imagen web de 272 × 281 píxeles como archivo maestro para impresión de gran formato.
- Para plantillas definitivas, solicitar al Área de Tecnología Educativa el original aprobado y confirmar las variantes autorizadas.

## Combinación de marcas

La relación entre la marca del Gobierno de Canarias, los niveles emisores y las submarcas debe seguir el Manual de Identidad Corporativa Gráfica. No se deben colocar los logotipos juntos por mera aproximación visual.

Antes de crear una cabecera o portada institucional hay que determinar:

1. el órgano emisor;
2. si ATE actúa como unidad, programa o submarca;
3. el modelo de marca del Gobierno aplicable;
4. el orden, tamaño, alineación y área de respeto;
5. las marcas colaboradoras o financiadoras que deban aparecer.
