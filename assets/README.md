# Recursos gráficos

Este directorio alojará recursos reutilizables autorizados para las plantillas del repositorio.

## Reglas

- Incorporar únicamente archivos obtenidos de fuentes oficiales o creados expresamente para ATE.
- Conservar el formato vectorial cuando exista.
- No modificar logotipos ni símbolos institucionales.
- Registrar procedencia, versión, licencia y fecha de descarga.
- Evitar duplicados y nombres ambiguos.
- No almacenar fotografías con datos personales sin base y autorización adecuadas.

## Estructura prevista

```text
assets/
├── logos/
├── icons/
├── images/
└── metadata/
```

Cada recurso deberá tener una entrada de metadatos antes de considerarse aprobado. Hasta que se incorporen archivos maestros oficiales, este directorio no debe usarse como fuente de logotipos.
