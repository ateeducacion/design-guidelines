# Crear una presentación

## Contexto obligatorio

Leer:

1. `../../DESIGN.md`
2. `../../design/presentaciones/DESIGN.md`
3. `../../references/ACCESIBILIDAD.md`
4. La plantilla aprobada, si existe.

## Flujo

1. Identificar audiencia, duración, objetivo y entorno de proyección.
2. Definir un relato con apertura, desarrollo, conclusiones y siguiente acción.
3. Convertir cada diapositiva en una idea principal con un título informativo.
4. Reducir texto y trasladar contexto ampliado a las notas.
5. Usar imágenes, diagramas y gráficos solo cuando expliquen contenido.
6. Revisar contraste, tamaños, orden de lectura y textos alternativos.
7. Ensayar el archivo en el formato y equipo de destino.

## Restricciones

- No llenar diapositivas con párrafos o listas extensas.
- No reducir tipografía para encajar contenido.
- No inventar datos, citas, fuentes ni recursos institucionales.
- No depender de animaciones para comprender el mensaje.

## Entregables

- Archivo editable.
- PDF accesible o material alternativo cuando proceda.
- Notas de la persona ponente.
- Relación de fuentes y recursos utilizados.
